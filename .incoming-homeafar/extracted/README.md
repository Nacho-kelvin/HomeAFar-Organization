# HomeAFar

Community website for HomeAFar (React + Vite + Supabase).

```
cd kelvin-natonia-redesigned-website
npm install
npm run dev      # local preview
npm test         # run the test suite
npm run build    # production build to dist/
```

Deploys on Vercel using the root `vercel.json`. Copy `.env.example` to `.env.local` and add the Supabase URL and anon key to enable the forms and /admin.
